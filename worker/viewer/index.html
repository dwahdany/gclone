Your vault, in this browser

This is the private web viewer and sign-in helper of one person's gclone, a tool that syncs encrypted files to their own Google Drive. Only its owner can sign in here; it serves nobody else.

  • This site signs you in with a redirect to Google and nothing else. It never asks you to enter a code at google.com/device. A page that does is not gclone.
  • Open this page from your bookmark or home-screen icon, and check that the address starts with https:// and this site's name.
  • Files are decrypted in this browser. The passphrase and the keys of a vault never leave it.
  • A sign-in on a device starts with gclone login in a terminal, and the code that terminal shows is entered at Google. Never enter a code that someone sent you.
