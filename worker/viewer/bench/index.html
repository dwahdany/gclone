Can this device unlock a vault?

This page runs what the hosted viewer does when it unlocks — the key derivation (Argon2id, 256 MiB, 3 passes) in a worker, then an index in memory — the way the viewer really does it: with a reload between rounds, with a reused worker for wrong passphrases, and without reloads. It takes about a minute, reloads itself several times and needs no input after "Start". Nothing leaves this page except the result, which goes to the computer that serves it.
